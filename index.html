Hints for your diagram
    Help

    Elements

    • Double-click an element to edit its text
    • Drag to move, Ctrl/Shift+click to select several
    • Shift+drag on the canvas: box selection
    • P primary key (underlined), F foreign key (overlined), W weak / identifying
    • Delete deletes the selection, Ctrl+A selects everything

    Lines

    • L or Line Tool, then click two elements
    • Click a cardinality to cycle through values, Shift+click to type any value
    • Right-click a line: double line (total participation)
    • Double-click a line: role name
    • Recursive relationship: connect the entity to the relationship twice
    • Delete Tool, then click a line to remove it

    General

    • Ctrl+Z undo, Ctrl+Y redo, Ctrl+S save project
    • Mouse wheel zooms, dragging the canvas pans, Esc cancels the current tool
    • Your work is saved automatically in this browser
